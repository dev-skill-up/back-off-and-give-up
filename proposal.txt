Modern applications depend on dozens of services and face unpredictable load patterns. When systems degrade, naive retry strategies can transform partial outages into complete failures through retry storms or resource exhaustion.

This talk offers practical solutions for building truly resilient systems by exploring:

1. **Exponential Back-off Fundamentals**
   - Why linear or fixed retries create "thundering herd" problems
   - How exponential back-off prevents amplifying system stress
   - Adding jitter (randomness) to prevent synchronized retry patterns
   - Implementation patterns in Python using standard library, asyncio, and packages like tenacity and backoff

2. **The Counterintuitive Value of Giving Up**
   - Why persistent retrying often makes congestion worse
   - Circuit breaker patterns with Python libraries like pybreaker and CircuitPython
   - Strategic load shedding techniques in Python services that preserve core functionality
   - How quick abandonment leads to faster recovery

3. **Putting It All Together**
   - Combining back-off and load shedding in a unified resilience strategy
   - Configuring appropriate timeouts with back-off in Python services
   - Instrumentation and monitoring

The talk includes practical Python code samples and configuration examples for common Python web frameworks and async services.

Attendees will leave with:
- Python implementation patterns for exponential back-off with jitter they can immediately apply
- Strategies for identifying which operations can be safely abandoned during degradation
- Python tools and libraries for measuring and quantifying the impact of different retry policies
- A mental framework for thinking about system resilience holistically in Python applications
